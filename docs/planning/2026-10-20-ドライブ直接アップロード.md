# ドライブ直接アップロード（R2 署名付き URL ＋ マルチパート）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cloudflare（Free / Pro）のリクエストボディ上限 100MB を回避し、最大 500MB のファイルをドライブへアップロードできるようにします。

**Architecture:** 90MB を超えるファイルは、ブラウザが R2 の S3 API エンドポイントへ署名付き URL でマルチパートアップロードします。Cloudflare のゾーンプロキシは経由しません。完了通知を受けたサーバーはオブジェクトを検証し、キューのジョブで R2 から一時ファイルへ取得して既存の `DriveService.addFile` に渡します。原本は再アップロードせず、`CopyObject` で正式なキーへ移します。クライアントは状態 API をポーリングして完成した `DriveFile` を受け取ります。

**Tech Stack:** NestJS / TypeORM / BullMQ / Redis / `@aws-sdk/client-s3` 3.1121.0 / `@aws-sdk/s3-request-presigner` 3.1121.0 / Vue 3 / vitest / aws-sdk-client-mock

**Spec:** 本計画書が仕様を兼ねます（前提となる議論は 2026-10-20 の Claude Code セッションで行いました）。

## Global Constraints

- アップロード上限は 500MB（`maxFileSize: 524288000`）とする
- 直接アップロードに切り替える閾値は 90MB（`90 * 1024 * 1024` バイト）とする。これ以下は既存の `drive/files/create` 経路のまま変えない
- パートサイズは 10MiB（`10 * 1024 * 1024`）とする。R2 の制約（最後以外のパートは同一サイズかつ 5MiB 以上）を満たす値である
- 署名付き URL の有効期限は 3 時間、Redis 上のアップロード状態の TTL は 24 時間とする
- 仮置きのキーは `${objectStoragePrefix}/direct-upload-pending/${uploadId}` とする（prefix が空なら `direct-upload-pending/${uploadId}`）
- 機能は `config.yml` の `enableDirectUpload: true` かつ `meta.useObjectStorage` が有効なときだけ使える。無効ならフロントエンドは既存経路に戻る
- 新規ファイルには SPDX ヘッダーを付ける（`node scripts/check-spdx.mjs --fix`）
- locale は `locales/ja-JP.yml` 以外を編集しない。本計画では既存の i18n キーだけを使い、locale は編集しない
- backend API を追加したら `pnpm build-misskey-js-with-types` を実行し、`packages/misskey-js/src/autogen/` の差分もコミットに含める
- `packages/backend/` を触る前に `working-on-backend` スキル、`packages/frontend/` を触る前に `working-on-frontend` スキルを読む
- コミット前・作業の引き渡し前には `shipping-misskey-change` スキルに従う。CHANGELOG は編集しない
- 作業ブランチは `origin/develop` から切る（`riin/feat/drive-direct-upload`）。mistems-main 上で直接作業しない
- upstream との差分を小さく保つため、既存ファイルの変更は最小限にとどめ、ロジックは新規ファイルに寄せる

## Review Focus

1. **申告サイズと実際のサイズが違う**: 各パートの署名に `content-length` を含めて改ざんを防ぎ、完了時は `HeadObject` で総サイズを照合する。不一致なら削除して `SIZE_MISMATCH` で失敗させる（Task 3 のテストで確認する）
2. **完了 API の二重呼び出し**: 2 回目は `INVALID_STATE` で拒否し、ジョブは 1 回だけ登録する（Task 3）
3. **他人の uploadId を指定された**: 状態の userId が一致しなければ `NO_SUCH_UPLOAD` を返し、存在も明かさない（Task 3）
4. **同一ハッシュのファイルがすでにある（`force: false`）**: `addFile` が既存ファイルを返す。仮置きオブジェクトは必ず削除する（Task 4）
5. **直接アップロードが使えないサーバー**: init が `DIRECT_UPLOAD_UNAVAILABLE` を返したら、フロントエンドは既存経路でアップロードを続ける（Task 6）

```ts
	@bindThis
	private buildObjectHeaders(type: string, ext: string | null | undefined, filename: string | undefined) {
		if (type === 'image/apng') type = 'image/png';
		if (!isBrowserSafeMime(type)) type = 'application/octet-stream';

		// S3 から直接配信される場合、ここで設定した ContentType がそのまま使われる。
		// text/* で charset 未指定だとブラウザが OS ロケールに基づくエンコーディングで解釈し
		// UTF-8 ファイルが文字化けするため、charset=utf-8 を補う。
		if (getBaseMime(type).startsWith('text/') && !type.includes('charset=')) {
			type = `${type}; charset=utf-8`;
		}

		const headers: Pick<PutObjectCommandInput, 'ContentType' | 'CacheControl' | 'ContentDisposition' | 'ACL'> = {
			ContentType: type,
			CacheControl: 'max-age=31536000, immutable',
		};

		if (filename) headers.ContentDisposition = contentDisposition(
			'inline',
			// 拡張子からContent-Typeを設定してそうな挙動を示すオブジェクトストレージ (upcloud?) も存在するので、
			// 許可されているファイル形式でしか拡張子をつけない
			ext ? correctFilename(filename, ext) : filename,
		);
		if (this.meta.objectStorageSetPublicRead) headers.ACL = 'public-read';

		return headers;
	}

	/**
	 * Upload to ObjectStorage
	 */
	@bindThis
	private async upload(key: string, stream: fs.ReadStream | Buffer, type: string, ext?: string | null, filename?: string) {
		const params = {
			Bucket: this.meta.objectStorageBucket,
			Key: key,
			Body: stream,
			...this.buildObjectHeaders(type, ext, filename),
		} as PutObjectCommandInput;

		await this.s3Service.upload(this.meta, params)
		// （以降の then / catch は既存のまま）
	}

	/**
	 * Move a directly uploaded original to its final key with proper headers.
	 * Unlike upload(), errors are thrown so that no DB record points to a missing object.
	 */
	@bindThis
	private async copyPreUploaded(srcKey: string, destKey: string, type: string, filename: string) {
		const bucket = this.meta.objectStorageBucket!;
		await this.s3Service.getS3Client(this.meta).send(new CopyObjectCommand({
			Bucket: bucket,
			Key: destKey,
			CopySource: `${bucket}/${srcKey.split('/').map(encodeURIComponent).join('/')}`,
			MetadataDirective: 'REPLACE',
			...this.buildObjectHeaders(type, null, filename),
		}));
	}
```

```ts
	'MAX_FILE_SIZE_EXCEEDED' | 'NO_FREE_SPACE' | 'UNALLOWED_FILE_TYPE' | 'INAPPROPRIATE' | 'FAILED';

		super(`Direct upload error: ${code}`);

	@bindThis
	public isAvailable(): boolean {
		return this.config.enableDirectUpload && this.meta.useObjectStorage && this.meta.objectStorageBucket != null;

	@bindThis
	public async init(user: MiLocalUser, args: DirectUploadInitArgs): Promise<{ uploadId: string; partSize: number; urls: string[] }> {
		if (!this.isAvailable()) throw new DirectUploadError('UNAVAILABLE');

		const partCount = Math.max(1, Math.ceil(args.size / DIRECT_UPLOAD_PART_SIZE));
		if (args.size > this.config.maxFileSize || partCount > DIRECT_UPLOAD_MAX_PARTS) {
			throw new DirectUploadError('MAX_FILE_SIZE_EXCEEDED');
		}

		// addFile でも同じ検査をするが、数百 MB を送らせる前に弾く
		if (!await this.roleService.isModerator(user)) {
			const policies = await this.roleService.getUserPolicies(user.id);
			if (args.size > policies.maxFileSizeMb * 1024 * 1024) throw new DirectUploadError('MAX_FILE_SIZE_EXCEEDED');
			const usage = await this.driveFileEntityService.calcDriveUsageOf(user);
			if (usage + args.size > policies.driveCapacityMb * 1024 * 1024) throw new DirectUploadError('NO_FREE_SPACE');
		}

		const uploadId = this.idService.gen();
		const prefix = this.meta.objectStoragePrefix ? `${this.meta.objectStoragePrefix}/` : '';
		const key = `${prefix}${PENDING_DIR}/${uploadId}`;
		const bucket = this.meta.objectStorageBucket!;
		const client = this.s3Service.getS3Client(this.meta);

		const created = await client.send(new CreateMultipartUploadCommand({ Bucket: bucket, Key: key }));
		if (created.UploadId == null) throw new DirectUploadError('FAILED');
		const s3UploadId = created.UploadId;

		const urls = await Promise.all(Array.from({ length: partCount }, (_, i) => {
			const partNumber = i + 1;
			const contentLength = partNumber < partCount
				? DIRECT_UPLOAD_PART_SIZE
				: args.size - DIRECT_UPLOAD_PART_SIZE * (partCount - 1);
			// content-length を署名に含め、申告と異なるサイズのパートを R2 側で拒否させる
			return getSignedUrl(client, new UploadPartCommand({
				Bucket: bucket,
				Key: key,
				UploadId: s3UploadId,
				PartNumber: partNumber,
				ContentLength: contentLength,
			}), {
				expiresIn: PRESIGN_EXPIRES_SEC,
				signableHeaders: new Set(['content-length']),
			});
		}));

		await this.saveState(uploadId, {
			...args,
			userId: user.id,
			key,
			s3UploadId,
			partCount,
			status: 'uploading',
			fileId: null,
			errorCode: null,
		});

		return { uploadId, partSize: DIRECT_UPLOAD_PART_SIZE, urls };
	}

	@bindThis
	public async complete(user: MiLocalUser, uploadId: string, parts: { partNumber: number; etag: string }[]): Promise<void> {
		const state = await this.getOwnState(user, uploadId);
		if (state.status !== 'uploading') throw new DirectUploadError('INVALID_STATE');

		const sorted = [...parts].sort((a, b) => a.partNumber - b.partNumber);
		if (sorted.length !== state.partCount || sorted.some((p, i) => p.partNumber !== i + 1)) {
			throw new DirectUploadError('INVALID_STATE');
		}

		// 二重 complete を防ぐ
		const locked = await this.redisClient.set(`${this.stateKey(uploadId)}:completing`, '1', 'EX', STATE_TTL_SEC, 'NX');
		if (locked !== 'OK') throw new DirectUploadError('INVALID_STATE');

		const bucket = this.meta.objectStorageBucket!;
		const client = this.s3Service.getS3Client(this.meta);

		try {
			await client.send(new CompleteMultipartUploadCommand({
				Bucket: bucket,
				Key: state.key,
				UploadId: state.s3UploadId,
				MultipartUpload: { Parts: sorted.map(p => ({ PartNumber: p.partNumber, ETag: p.etag })) },
			}));
		} catch {
			await client.send(new AbortMultipartUploadCommand({ Bucket: bucket, Key: state.key, UploadId: state.s3UploadId })).catch(() => {});
			await this.saveState(uploadId, { ...state, status: 'failed', errorCode: 'FAILED' });
			throw new DirectUploadError('FAILED');
		}

		const head = await client.send(new HeadObjectCommand({ Bucket: bucket, Key: state.key }));
		if (head.ContentLength !== state.size) {
			await this.driveService.deleteObjectStorageFile(state.key);
			await this.saveState(uploadId, { ...state, status: 'failed', errorCode: 'SIZE_MISMATCH' });
			throw new DirectUploadError('SIZE_MISMATCH');
		}

		await this.saveState(uploadId, { ...state, status: 'processing' });
		await this.queueService.createFinalizeDirectUploadJob(uploadId);
	}

	@bindThis
	public async abort(user: MiLocalUser, uploadId: string): Promise<void> {
		const state = await this.getOwnState(user, uploadId);
		if (state.status === 'uploading') {
			await this.s3Service.getS3Client(this.meta).send(new AbortMultipartUploadCommand({
				Bucket: this.meta.objectStorageBucket!,
				Key: state.key,
				UploadId: state.s3UploadId,
			})).catch(() => {});
		}
		await this.redisClient.del(this.stateKey(uploadId));
	}

	@bindThis
	public async getStatus(user: MiLocalUser, uploadId: string): Promise<{ status: DirectUploadStatus; fileId: string | null; errorCode: DirectUploadErrorCode | null }> {
		const state = await this.getOwnState(user, uploadId);
		return { status: state.status, fileId: state.fileId, errorCode: state.errorCode };
	}

	@bindThis
	public async finalize(uploadId: string): Promise<void> {
		// Task 4 で実装する
		throw new Error('not implemented');
	}

	private stateKey(uploadId: string): string {
		return `directUpload:${uploadId}`;
	}

	@bindThis
	private async loadState(uploadId: string): Promise<DirectUploadState | null> {
		const raw = await this.redisClient.get(this.stateKey(uploadId));
		return raw == null ? null : JSON.parse(raw) as DirectUploadState;
	}

	@bindThis
	private async getOwnState(user: MiLocalUser, uploadId: string): Promise<DirectUploadState> {
		const state = await this.loadState(uploadId);
		if (state == null || state.userId !== user.id) throw new DirectUploadError('NO_SUCH_UPLOAD');
		return state;
	}

	@bindThis

		await this.redisClient.set(this.stateKey(uploadId), JSON.stringify(state), 'EX', STATE_TTL_SEC);
	}
}
```

```ts
	@bindThis
	public async finalize(uploadId: string): Promise<void> {
		const state = await this.loadState(uploadId);
		if (state == null || state.status !== 'processing') return;

		const [path, cleanup] = await createTemp();
		try {
			const obj = await this.s3Service.getS3Client(this.meta).send(new GetObjectCommand({
				Bucket: this.meta.objectStorageBucket!,
				Key: state.key,
			}));
			await pipeline(obj.Body as Readable, fs.createWriteStream(path));

			const user = await this.usersRepository.findOneByOrFail({ id: state.userId });
			const file = await this.driveService.addFile({
				user,
				path,
				name: state.name,
				comment: state.comment,
				folderId: state.folderId,
				force: state.force,
				sensitive: state.isSensitive,
				requestIp: state.requestIp,
				requestHeaders: state.requestHeaders,
				preUploadedKey: state.key,
			});
			await this.saveState(uploadId, { ...state, status: 'done', fileId: file.id });
		} catch (err) {
			const errorCode = err instanceof IdentifiableError ? (ADD_FILE_ERROR_CODES[err.id] ?? 'FAILED') : 'FAILED';
			await this.saveState(uploadId, { ...state, status: 'failed', errorCode });
			// ユーザー起因でない失敗はジョブの失敗として残し、管理画面のキューから追えるようにする
			if (errorCode === 'FAILED') throw err;
		} finally {
			cleanup();
			// 成功時は CopyObject 済み、失敗時・重複時は不要なので、どの場合も削除する
			await this.driveService.deleteObjectStorageFile(state.key).catch(() => {});
		}
	}
```

```ts
/*
 * SPDX-FileCopyrightText: syuilo and misskey-project
 * SPDX-License-Identifier: AGPL-3.0-only
 */

import * as Misskey from 'misskey-js';
import * as os from '@/os.js';
import { misskeyApi } from '@/utility/misskey-api.js';
import { i18n } from '@/i18n.js';
import { globalEvents } from '@/events.js';

// Cloudflare (Free / Pro) のリクエストボディ上限 100MB に余裕を持たせた閾値
export const DIRECT_UPLOAD_THRESHOLD = 90 * 1024 * 1024;
const CONCURRENCY = 4;
const PART_RETRIES = 3;
const POLL_INTERVAL_MS = 2000;
const POLL_TIMEOUT_MS = 30 * 60 * 1000;

export class DirectUploadUnavailableError extends Error {
	constructor() {
		super('Direct upload is unavailable');
	}
}

export class DirectUploadAbortedError extends Error {
	constructor() {
		super('Upload aborted');
	}
}

type UploadOptions = {
	name?: string;
	folderId?: string | null;
	isSensitive?: boolean;
	caption?: string | null;
	onProgress?: (ctx: { total: number; loaded: number; }) => void;
};

export function splitParts(size: number, partSize: number): { partNumber: number; start: number; end: number }[] {
	const count = Math.max(1, Math.ceil(size / partSize));
	return Array.from({ length: count }, (_, i) => ({
		partNumber: i + 1,
		start: i * partSize,
		end: Math.min(size, (i + 1) * partSize),
	}));
}

export async function runWithConcurrency<T>(tasks: (() => Promise<T>)[], concurrency: number): Promise<T[]> {
	const results: T[] = new Array(tasks.length);
	let next = 0;
	const worker = async () => {
		while (next < tasks.length) {
			const i = next++;
			results[i] = await tasks[i]();
		}
	};
	await Promise.all(Array.from({ length: Math.min(concurrency, tasks.length) }, worker));
	return results;
}

function putPart(url: string, body: Blob, xhrs: Set<XMLHttpRequest>, onProgress: (loaded: number) => void): Promise<string> {
	return new Promise((resolve, reject) => {
		const xhr = new XMLHttpRequest();
		xhrs.add(xhr);
		xhr.open('PUT', url, true);
		xhr.upload.onprogress = ev => onProgress(ev.loaded);
		xhr.onload = () => {
			xhrs.delete(xhr);
			const etag = xhr.getResponseHeader('ETag');
			if (xhr.status >= 200 && xhr.status < 300 && etag != null) resolve(etag);
			else reject(new Error(`part upload failed: ${xhr.status}`));
		};
		xhr.onerror = () => { xhrs.delete(xhr); reject(new Error('part upload network error')); };
		xhr.onabort = () => { xhrs.delete(xhr); reject(new DirectUploadAbortedError()); };
		xhr.send(body);
	});
}

async function putPartWithRetry(url: string, body: Blob, xhrs: Set<XMLHttpRequest>, onProgress: (loaded: number) => void): Promise<string> {
	for (let attempt = 1; ; attempt++) {
		try {
			return await putPart(url, body, xhrs, onProgress);
		} catch (err) {
			if (err instanceof DirectUploadAbortedError || attempt >= PART_RETRIES) throw err;
			onProgress(0);
			await new Promise(r => setTimeout(r, 1000 * attempt));
		}
	}
}

function alertUploadError(code: string | null | undefined) {
	const text =
		code === 'MAX_FILE_SIZE_EXCEEDED' ? i18n.ts.cannotUploadBecauseExceedsFileSizeLimit :
		code === 'NO_FREE_SPACE' ? i18n.ts.cannotUploadBecauseNoFreeSpace :
		code === 'UNALLOWED_FILE_TYPE' ? i18n.ts.cannotUploadBecauseUnallowedFileType :
		code === 'INAPPROPRIATE' ? i18n.ts.cannotUploadBecauseInappropriate :
		code ?? '';
	os.alert({ type: 'error', title: i18n.ts.failedToUpload, text });
}

export function directUploadFile(file: File | Blob, options: UploadOptions = {}): { filePromise: Promise<Misskey.entities.DriveFile>; abort: () => void } {
	const xhrs = new Set<XMLHttpRequest>();
	let aborted = false;
	let uploadId: string | null = null;

	const filePromise = (async () => {
		let init: Misskey.entities.DriveFilesDirectUploadInitResponse;
		try {
			init = await misskeyApi('drive/files/direct-upload/init', {
				size: file.size,
				name: options.name ?? (file instanceof File ? file.name : null),
				folderId: options.folderId ?? null,
				comment: options.caption ?? null,
				isSensitive: options.isSensitive ?? false,
				force: true,
			});
		} catch (err) {
			if ((err as { code?: string }).code === 'DIRECT_UPLOAD_UNAVAILABLE') throw new DirectUploadUnavailableError();
			alertUploadError((err as { code?: string }).code);
			throw err;
		}
		uploadId = init.uploadId;

		const parts = splitParts(file.size, init.partSize);
		const loadedByPart = new Array<number>(parts.length).fill(0);
		const report = () => options.onProgress?.({ total: file.size, loaded: loadedByPart.reduce((a, b) => a + b, 0) });

		const etags = await runWithConcurrency(parts.map((p, i) => () => {
			if (aborted) throw new DirectUploadAbortedError();
			return putPartWithRetry(init.urls[i], file.slice(p.start, p.end), xhrs, loaded => {
				loadedByPart[i] = loaded;
				report();
			});
		}), CONCURRENCY);

		await misskeyApi('drive/files/direct-upload/complete', {
			uploadId: init.uploadId,
			parts: parts.map((p, i) => ({ partNumber: p.partNumber, etag: etags[i] })),
		});

		const deadline = Date.now() + POLL_TIMEOUT_MS;
		while (Date.now() < deadline) {
			if (aborted) throw new DirectUploadAbortedError();
			await new Promise(r => setTimeout(r, POLL_INTERVAL_MS));
			const s = await misskeyApi('drive/files/direct-upload/status', { uploadId: init.uploadId });
			if (s.status === 'done' && s.file != null) {
				globalEvents.emit('driveFileCreated', s.file);
				return s.file;
			}
			if (s.status === 'failed') {
				alertUploadError(s.errorCode);
				throw new Error(`direct upload failed: ${s.errorCode}`);
			}
		}
		alertUploadError(null);
		throw new Error('direct upload timed out');
	})();

	const abort = () => {
		aborted = true;
		for (const xhr of xhrs) xhr.abort();
		if (uploadId != null) misskeyApi('drive/files/direct-upload/abort', { uploadId }).catch(() => {});
	};

	return { filePromise, abort };
}
```

```ts
import { DIRECT_UPLOAD_THRESHOLD, DirectUploadAbortedError, DirectUploadUnavailableError, directUploadFile } from '@/utility/drive-direct-upload.js';

type UploadOptions = Parameters<typeof uploadFileLegacy>[1];

export function uploadFile(file: File | Blob, options: UploadOptions = {}): UploadReturnType {
	if (file.size <= DIRECT_UPLOAD_THRESHOLD || $i == null) return uploadFileLegacy(file, options);

	const direct = directUploadFile(file, options);
	let legacy: UploadReturnType | null = null;
	const filePromise = direct.filePromise.catch(err => {
		if (err instanceof DirectUploadAbortedError) throw new UploadAbortedError();
		if (!(err instanceof DirectUploadUnavailableError)) throw err;
		// 直接アップロードが使えないサーバーでは従来経路で送る
		legacy = uploadFileLegacy(file, options);
		return legacy.filePromise;
	});

	return {
		filePromise,
		abort: () => {
			direct.abort();
			legacy?.abort();
		},
	};
}

function uploadFileLegacy(file: File | Blob, options: {
	// 既存の引数定義をそのまま残す
} = {}): UploadReturnType {
	// 既存の本体をそのまま残す
}
```
